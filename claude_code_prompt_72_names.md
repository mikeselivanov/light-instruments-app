# Задача: добавить три новых инструмента в приложение "72 Имени Бога"

## Контекст

Это мобильное приложение, в котором уже реализовано отображение 72 Имён Бога
(Шем ха-Мефораш). Нужно добавить три новых, самостоятельных инструмента —
медитативные практики, основанные на еврейской мистической традиции
(источники: Абрахам Абулафия, Арье Каплан "Meditation and Kabbalah", "Сефер
Йецира"). Контент и логика всех трёх практик уже проработаны — ниже даётся
полная спецификация. Твоя задача — реализовать их в существующем проекте,
следуя его текущей архитектуре, стеку и визуальному языку.

**Прежде чем писать код:**
1. Изучи структуру репозитория, стек (React Native / Flutter / нативный
   iOS/Android / другое), текущую навигацию, систему локализации, принятые
   паттерны компонентов и state management.
2. Проверь, используется ли уже в проекте шрифт для ивритских букв (вероятно,
   `Ashurit.ttf` или аналог — он нужен для всех трёх фич) — где он подключён,
   как обычно рендерится иврит.
3. Посмотри, есть ли уже в приложении экран/раздел для доп. инструментов или
   практик, куда логично встроить эти три фичи, или нужен новый раздел меню.
4. Предложи мне краткий план (список экранов/компонентов, где именно в
   навигации это появится, какие переиспользуемые части уже есть) **до**
   того, как начнёшь писать реализацию — чтобы я мог сориентироваться и
   поправить, если что-то не так.
5. Дальше реализуй по одной фиче за раз, отдельными логическими шагами
   (коммитами/PR), не всё сразу одним большим изменением.

## Общие принципы для всех трёх фич

- **Тон и эстетика**: спокойный, созерцательный, без игровой геймификации,
  без "начислений очков" или соревновательных элементов. Это инструменты для
  тихой практики, не мини-игры.
- **Иврит**: буквы рендерятся предоставленным шрифтом (Ashurit или тот, что
  уже используется в приложении для 72 Имён). Важно: при выводе многобуквенных
  ивритских строк (например, полного Тетраграмматона) следи за корректным
  визуальным порядком RTL — сверься с тем, как это уже решено в существующем
  коде для вывода 72 Имён.
- **Без принуждения к результату**: нигде не должно быть текста в духе
  "выполнено на X%" или давления на регулярность — только мягкие
  напоминания-таймеры.
- **Тёмная/светлая тема**: все три экрана должны корректно работать в обеих
  темах приложения (если тема уже поддерживается) — контраст важен, так как
  часть практик подразумевает созерцание при слабом освещении (вечер).
- **Локализация**: контент ниже дан на русском — вставь его через
  существующую систему локализации проекта (i18n), не хардкодь строки, если
  в проекте уже принят другой подход.
- **Доступность**: учти VoiceOver/TalkBack для не визуальных частей (кнопки,
  таймеры), но НЕ нужно озвучивать сами практики голосом — это тихие,
  визуальные/дыхательные инструменты.

## Фича 1: Дыхательная медитация на Тетраграмматон

### Суть практики
Синхронизация естественного дыхания (без форсирования ритма) с четырьмя
буквами Тетраграмматона (יהוה), каждая буква — одна фаза дыхательного цикла:

| Буква | Фаза | Пояснение |
|---|---|---|
| י (йуд) | вдох | искра, начало |
| ה (хей) | пауза после вдоха | раскрытие |
| ו (вав) | выдох | продолжение, связь |
| ה (хей) | пауза после выдоха | покой |

Имя не произносится вслух — только визуально / мысленно.

### UX-флоу
1. Вводный экран с кратким описанием практики (2-3 предложения) и кнопкой
   "Начать".
2. Настройка длительности сессии: пресеты 3 / 5 / 10 минут (без ввода
   произвольного числа — простота важнее гибкости).
3. Экран практики:
   - крупно по центру — текущая буква цикла (плавная смена между
     И/Х/В/Х при переходе фаз);
   - мягкая визуальная индикация фазы (например, расширяющийся/сужающийся
     круг или полупрозрачный градиент — БЕЗ жёстко навязанного ритма в
     секундах: фазы должны подстраиваться под то, что пользователь сам
     инициирует переходом, либо — если делается автотаймер — дать
     пользователю самому один раз откалибровать длительность вдоха/выдоха
     в начале сессии касанием экрана, а дальше использовать этот ритм);
   - ненавязчивая кнопка паузы/выхода, доступная всегда;
   - никакого звука/музыки по умолчанию (опционально — тихий, едва
     заметный сигнал смены фазы, выключаемый в настройках).
4. По окончании сессии — простой экран завершения без "статистики
   выполнения", максимум — мягкое "сессия завершена" и кнопка "назад".

### Технические заметки
- Реализуй калибровку ритма как отдельный переиспользуемый модуль — он,
  вероятно, пригодится и в других будущих дыхательных практиках приложения.
- Анимация фаз должна быть плавной (interpolation), не резкой сменой кадров.

## Фича 2: Созерцательная медитация на букве

### Суть практики
Чистое визуальное созерцание формы одной ивритской буквы, без называния
звука и без размышления о значении. Начинается с йуд как самой простой по
форме буквы.

### Набор букв для первой версии
- **י (йуд)** — "изначальная точка, исток, малость — начни с неё"
- **א (алеф)** — "безмолвная опора, единство, дыхание перед звуком"
- **ה (хей)** — "раскрытие, дыхание, откровение"
- **ו (вав)** — "связь, продолжение, соединение"

(Список сделай расширяемым — в будущем логично добавить весь алфавит из 22
букв; сейчас реализуй архитектуру данных так, чтобы добавление новой буквы
было конфигурацией, а не новым кодом.)

### UX-флоу
1. Список/карусель из 4 букв с кратким пояснением к каждой (текст выше) —
   пользователь выбирает букву.
2. Экран созерцания:
   - буква рендерится крупно по центру, статично (без анимации — сама идея
     практики в неподвижном созерцании формы);
   - два визуальных варианта, между которыми можно переключиться:
     тёмный фон + буква цветом (например, тёплое золото) — для вечерней
     практики; светлый фон + чёрная буква — для дневной / печатной
     аналогии;
   - таймер на 3 / 5 минут (пресеты, без произвольного ввода);
   - в момент окончания — мягкое затухание экрана (fade), без звукового
     сигнала по умолчанию.
3. Никакого прогресса, никаких "пройдено X букв" — каждая буква доступна
   в любой момент, без "открытия по порядку".

### Технические заметки
- Подготовь буквы как переиспользуемый data-конфиг: `{ letter: "י", name:
  "ЙУД", note: "..." }` — так проще расширять позже до полного алфавита.
- Если в приложении уже есть похожий "просмотрщик" отдельных Имён (72
  Имени наверняка показываются похожим образом крупным планом) — переиспользуй
  этот компонент вместо написания нового с нуля.

## Фича 3: Колесо Галгал (231 врат)

### Суть
Основано на "Сефер Йецира": 22 буквы, взятые попарно без повторов, дают 231
"врата" — базовую комбинаторную решётку. Традиционно изображается как круг
из 22 букв.

### Контент
Полный алфавит по порядку (для расположения по кругу):
```
א ב ג ד ה ו ז ח ט י כ ל מ נ ס ע פ צ ק ר ש ת
алеф, бет, гимель, далет, хей, вав, заин, хет, тет, йуд, каф,
ламед, мем, нун, самех, аин, пей, цади, куф, реш, шин, тав
```

### UX-флоу
1. Вводный экран с кратким пояснением (2-4 предложения, текст ниже можно
   использовать как основу):
   > "22 буквы, взятые попарно без повторов, дают 231 «врата» — базовую
   > решётку, через которую, согласно тексту, было сотворено мироздание.
   > Буквы расположены по кругу. Коснись двух букв, чтобы увидеть
   > образуемые ими врата."
2. Основной экран — интерактивное колесо:
   - 22 буквы расположены равномерно по кругу (как в уже подготовленном
     PDF-варианте — можешь использовать ту же логику раскладки по
     окружности: угол = `π/2 - 2π·i/22`, чтобы начать сверху и идти по
     часовой стрелке);
   - пользователь касается первой буквы (она визуально выделяется —
     подсветка/увеличение), затем второй;
   - после выбора двух букв — снизу или в модальном окне показывается
     образованная пара ("врата"): обе буквы вместе в правильном RTL-порядке
     (например, "алеф-бет" → אב), плюс, если есть время на первую версию,
     — краткая пометка про категорию букв (материнская / двойная / простая),
     см. ниже;
   - в центре круга — статичная подпись "231 врата" (как декоративный
     элемент, не интерактивный).
3. Дополнительно (не обязательно для MVP, но желательно): режим
   "автоматического обхода" — при котором одна буква зафиксирована (например,
   алеф), и пользователь может пролистать все её пары с остальными 21
   буквой по очереди — это прямое переиспользование того, что уже
   отработано в PDF-варианте (таблица "алеф + все буквы").

### Категории букв (для будущего расширения, но структуру данных заложи сразу)
- **3 материнские**: א (алеф), מ (мем), ש (шин) — воздух/вода/огонь
- **7 двойных**: ב ג ד כ פ ר ת (бет, гимель, далет, каф, пей, реш, тав)
- **12 простых**: остальные

### Технические заметки
- Расположение по кругу — чистая тригонометрия (`sin`/`cos`), не нужна
  сторонняя библиотека диаграмм, если в проекте уже есть слой для
  кастомной отрисовки (Canvas / SVG / native drawing — в зависимости от
  стека, определи сам).
- Убедись, что круг корректно масштабируется под разные размеры экрана
  (маленькие телефоны — буквы не должны налезать друг на друга; проверь
  минимальный tap-target ~44pt для каждой буквы).
- Данные по 22 буквам, их категориям и порядку вынеси в отдельный
  конфиг-файл/константу — это, вероятно, переиспользуется и в других
  местах приложения (у вас уже наверняка есть где-то канонический список
  22 букв для 72 Имён).

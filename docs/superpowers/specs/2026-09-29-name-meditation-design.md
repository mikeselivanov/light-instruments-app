# Медитативный режим на экране имени — дизайн

Дата: 2026-09-29
Статус: на согласовании.

## Контекст

На экране имени (`app/names/[id].tsx`) рядом с самим именем много всего:
- номер имени, название, теги;
- кнопки навигации «‹ ⌂ ›», «В избранное», «Случайное»;
- прокручиваемое описание.

Для медитации на имени всё это лишнее. Нужен режим, в котором на экране остаётся только
имя.

## Решения

**Вход — кнопкой, выход — касанием в любом месте.**
- Вход по тапу в любое место экрана конфликтовал бы с тем, что на экране уже есть:
  - тап останавливает прокрутку описания;
  - касанием начинают выделять текст описания (`selectableText`);
  - экран листается свайпом.
  Режим включался бы случайно. И его никто бы не нашёл: невидимый жест — ровно та
  проблема, из-за которой свайп между именами пришлось продублировать кнопками
  (комментарий в `app/names/[id].tsx`).
- В самом режиме на экране нет ничего, кроме букв, поэтому выход касанием ни с чем не
  конфликтует. Это самый спокойный жест из возможных.

**Кнопка входа — круглая иконка в верхнем ряду, рядом с «Домой».**
- Ряд становится таким: `‹   ⌂ ◎   ›`.
- Иконка `IconButton` со значком Ionicons `eye-outline`, подпись для экранного диктора
  «Созерцать имя».
- Почему не третья кнопка-пилюля рядом с «В избранное» и «Случайное»: «☆ В избранное»,
  «↻ Случайное» и «◎ Созерцать» вместе занимают около 388 pt, а доступно 350 pt на
  телефоне шириной 390 pt и 280 pt на телефоне шириной 320 pt.

**В режиме — только буквы, крупнее.**
- Остаются три буквы с маленькими точками между ними.
- Буквы цвета `parchment`, точки — `parchmentDim`, их размер берётся из
  `DISPLAY_DOT_RATIO`, как у крупного имени на экране.
- Без подписей «ЛАМЕД · АЛЕФ · ВАВ», без названия и номера.
- Буквы стоят по центру экрана.
- Размер подбирается по ширине: `min(200, floor(112 × доступная ширина / 240,5))`. Здесь
  240,5 pt — ширина самого широкого из 72 имён при кегле 112 (замер из `HebrewGlyphs`).
  На телефоне шириной 390 pt выходит около 163 pt вместо нынешних 112.

**Подсказка про выход.**
- При входе внизу экрана появляется строка «Коснитесь, чтобы вернуться».
- Через 3 секунды она плавно гаснет и больше не показывается, пока человек не выйдет из
  режима и не войдёт снова.
- Без неё первый вход оставлял бы человека перед экраном без единого элемента управления.

**Пока режим включён:**
- Экран не гаснет: используется `useWakeLock` из практик.
- Свайп между именами выключен: случайное движение не должно сменить имя посреди
  медитации.
- На телефоне прячется системная строка статуса: `StatusBar hidden` из
  `expo-status-bar`. В вебе это ничего не делает.
- Вход и выход — плавная смена прозрачности, около 300 мс.

**Режим — локальное состояние экрана.** Он нигде не сохраняется: ушли с экрана — режим
выключен.

## Компоненты

- `components/HebrewGlyphs.tsx`: новый вариант `variant="bare"` с пропом `size`. Это
  буквы, как в `display` (цвет, точка `DISPLAY_DOT_RATIO`, сдвиг точки `DOT_DROP`,
  порядок справа налево, конечные формы), но без подписей. Расстояние между колонками
  масштабируется от `DISPLAY.columnGap` пропорционально `size / 112`.
- `app/names/[id].tsx`:
  - состояние `meditating`;
  - иконка входа в ряду навигации;
  - в режиме рисуется полноэкранный `Pressable` с буквами (`accessibilityLabel`
    «Выйти из созерцания»), обычное содержимое экрана скрыто;
  - `Gesture.Pan().enabled(!meditating)`;
  - `useWakeLock(meditating)`;
  - `<StatusBar hidden />` в режиме.

## Проверка

Проверка идёт в вебе через Playwright с эмуляцией касаний, как в прошлой функции.
Проверяется:
- касание иконки «Созерцать имя» включает режим: на экране нет ни названия, ни кнопок, ни
  описания, подсказка видна, а через 3,5 с не видна;
- касание в любом месте выключает режим, и экран возвращается к исходному виду;
- свайп в режиме не меняет имя (URL остаётся `/names/N`);
- самое широкое имя помещается по ширине на экране шириной 320 pt;
- `npx tsc --noEmit` проходит без ошибок.

Скриншоты режима на ширине 390 и 320 pt я смотрю сам.
